# Icosahedron sculpture and web presentation

A visual documentation project for an icosahedron sculpture. The site presents photographs and the mathematical form that connects a hands-on object to Jonathan's interest in geometry.

[View the photo presentation](https://jonathandoanephd.github.io/Website_Icosahedron/)

## Repository contents

- `index.html` and `assets/`: the presentation site
- `images/`: photographs and site imagery
- `html5up-landed_LICENSE.txt` and `html5up-landed_README.txt`: attribution and terms for the HTML5 UP Landed template used by the site

This is a personal mathematics and making project. The [research portfolio](https://jonathandoanephd.github.io/research-portfolio/) is the current professional landing page. The website source and imagery may have different rights; see the included template license, and ask before reusing original photographs.
